# BeloraSupport v1.0.0

Единая система заявок в фан-клуб для Telegram и VK.

## Telegram
- Пошаговая анкета
- Предпросмотр
- SQLite
- Уведомление администраторов
- Одобрение/отклонение
- Причина отклонения
- Защита от повторной активной заявки

## Pterodactyl
Startup command:

python -m pip install -r requirements.txt && python start.py

## Environment
Скопируй `.env.example` в `.env` и заполни токены.

ADMIN_IDS — Telegram ID администраторов через запятую.

Никогда не публикуй токены в GitHub.


## Управление администраторами

Владелец задаётся через `OWNER_TG_ID` и является единственным пользователем, который может менять состав администраторов.

В Telegram:
- `/addadmin tg ID` — добавить администратора Telegram.
- `/addadmin vk ID` — добавить администратора VK.
- `/deladmin tg ID` — удалить Telegram-администратора.
- `/deladmin vk ID` — удалить VK-администратора.
- `/admins` — посмотреть списки.

Администраторы хранятся в SQLite, поэтому изменения не нужно прописывать в `.env`.

Для VK-владельца предусмотрен `OWNER_VK_ID`; управление VK-администраторами будет доступно и из VK после подключения полной VK-панели.
